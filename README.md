# 无限庭院 · Manifold Garden（HTML 复刻）

一部致敬 William Chyr《Manifold Garden》（中文名《无限宫院》，玩家常称《无限庭院》）的网页复刻：
六向重力、三轴无限循环的世界、同色方块与插槽、会寻找落差的水、浇灌后结出方块的树。

**成品**：`dist/无限庭院.html`（单文件、完全离线，约 145 KB；`dist/index.html` 为同一文件的副本）。
直接用 Chrome / Edge / Firefox / Safari 打开即可游玩，建议键鼠 + 耳机。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 行走（Shift 快步） |
| 空格 | 跳跃 |
| 鼠标右键 / F | 看向墙面或天花板，让它成为地面 |
| 鼠标左键 / E | 拿起、放下、放入插槽 |
| R（连按两次） | 重置当前庭院 |
| H | 重新显示提示 |
| Esc | 暂停 |
| \` | 性能信息 |

触屏设备：左侧拖动行走、右侧滑动环顾，右下角按钮为「重力 / 拿取 / 跳」。

## 八座庭院

| # | 名称 | 机制 |
| --- | --- | --- |
| 1 | 初醒 | 改变重力，沿墙走过裂隙 |
| 2 | 坠落 | 世界首尾相连：坠入虚空，从天而降 |
| 3 | 方块 | 只能拿起同色方块；双色插槽开门 |
| 4 | 回环 | 让方块坠入虚空，绕回落在够不着的插槽上 |
| 5 | 悬停 | 异色方块冻结在空中，成为抱着方块攀登的台阶 |
| 6 | 水 | 用方块截断水渠，让水改道浇灌树木，收获果实方块 |
| 7 | 倒悬 | 金之重力：向“上”坠落，插槽在平台底面 |
| 8 | 庭院之心 | 三种颜色、横向瀑布、浮岛与倒悬的综合谜题 → 结局 |

## 构建

```bash
npm install          # 仅需 esbuild
node build.mjs       # 生产构建（压缩）→ dist/无限庭院.html
node build.mjs --dev # 不压缩，便于调试
```

## 技术要点

- **无限世界**：关卡是一个周期体素盒，所有查询对尺寸取模；渲染时把同一份静态网格按视锥与雾距剔除后
  `drawElementsInstanced` 成数百个副本，远处副本溶进与天空同色的雾里。
- **画风**：G-buffer 输出颜色 / 法线 / 物体编号 / 深度；合成阶段用 `1/z` 的二阶差分检测轮廓（平面上恒为零，
  掠射角不误判）、法线差检测折痕，只在一侧画线得到 1 像素描边；再叠加距离雾、泛光、柔和高光压缩与 FXAA。
- **阴影**：由于所有副本完全相同，只需在局部坐标里渲染一张覆盖周期盒的正交阴影贴图，所有副本共享。
- **水**：每 50ms 从水源做一次 BFS——能下落就下落，被挡住就沿表面铺开并优先流向最近的落差（≤6 格）；
  坠入虚空的水会绕回世界形成闭环瀑布，用“首次抵达来源”逐格生长以避免闭环死锁。
- **重力翻转**：姿态四元数绕旧上方向到新上方向的最短旋转（天花板则绕视线右轴 180°），yaw/pitch 保持不变，
  结束后吸附到轴对齐姿态消除误差。
- **声音**：全部由 WebAudio 实时合成，无任何音频文件；每座庭院有自己的调式。
